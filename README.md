Программа на python для переноса с трансформацией (ETL), миграции, синхронизации данных между различными источниками данных. Гибкие конфигурационные файлы позволяют настраивать ее работу для разных случаев:
- миграция в CMS OpenCart (с программой поставляется как пример конфигурации -  миграция с OpenCart 1.5 на oc 3)
- сложный перенос и модифицирование данных в процессе переноса 
- синхронизация данных по расписанию 

Различные источники данных: mysql, sql, csv, список со временем можно дополнить, например Microsoft Access или 1С.

# Основные возможности программы:

Графический интерфейс (GUI) 
**Разные типы источников данных:** Поддерживаются CSV-файлы, базы данных SQLite и MySQL как для источника, так и для приемника данных.
Конфигурирование переноса:
   - Вкладка "Configuration": Позволяет загружать, сохранять и редактировать JSON-файлы конфигурации, определяющие, откуда и куда переносить данные, какие таблицы/файлы использовать, какие поля и т.д.
   - Вкладка "Transformed Config": Предлагает возможность трансформировать конфигурацию на основе схем данных источника и приемника.

### Анализ схем данных:

   - Вкладки "Source Schema" и "Destination Schema": Позволяют подключиться к источникам данных и визуализировать их структуру (таблицы, столбцы, типы данных и т.п.).
   - Вкладка "Table": Позволяет выбрать таблицу из схемы и загрузить для предварительного просмотра первые 10 строк данных из неё.

### Сравнение и синхронизация данных:

   - Программа может сравнивать данные в источнике и приемнике по заданным ключевым полям.
   - Определяет записи, которые нужно вставить, обновить или удалить в приемнике, чтобы он соответствовал источнику.

### Преобразование данных:

   - Поддержка пользовательских функций преобразования данных как до, так и после сравнения. 
Это позволяет изменять формат или содержание данных перед их записью в приемник.

### Выполнение переноса:

   - Вкладка "Execution": Содержит кнопки для запуска (Run Transfer) и остановки процесса.
     Отображает прогресс выполнения и количество записей, подлежащих вставке, обновлению и удалению.
     Показывает результаты выполнения операций.

### Ведение логов:

   - Вкладка "Logs": Отображает подробные сообщения о ходе выполнения операций, включая ошибки и предупреждения. 
Это помогает отслеживать и отлаживать процесс переноса.

# Использование конфигураций и принцип работы программы:
Программа получает инструкцию из конфига .json, для каждой таблицы БД выполняется команды:
-выборка данных из источника и приемника
- модификация (скрипты Python)
- сравнение и получение списков для вставки, обновления и удаления в приемнике
- модификация этих 3 списков (скрипты Python)
- выполнение операций над приемником.

### Параметры подключения к mysql-базе
    "source": {
        "type": "sql",  # mysql, sql, csv
        "connection_params": {
            "host": "",
            "port": 3306,
            "user": "",
            "password": "",
            "database": "",
            "charset": "utf8mb4"
                }
            }
### параметры подключения к csv, для SQL lite достаточно указать "path"
    "destination": {
        "type": "csv",
        "connection_params": {  
            "path": "test.csv",
            "delimiter": ","
        }
    }
###  Список заданий, которые программа последовательно выполняет - ключ jobs
Список одинаковых таблиц в источнике и приемнике, программа берет одинаковые поля, остальные поля не учитываются
      "jobs": [
        {"tables":  
             ["талица1", "таблица2", "..."] 
         }, 
        ]
###   Для сложного переноса - query и модификаторы
       {"source": {
            "query": "",  # sql-запрос для сложной выборки, для csv это путь файла
            "columns": []
        },
            "destination": {
                "table": "",  # может быть query для сложной выборки
                "columns": []
            },
            "transformation": {
                "source_path": "", # путь для скрипта на Python для трансформации после выборки
                "destination_path": "", # то же и для приемника, например "jobs/oc15_to_oc3/oc_currency.py"
                "transform_upd_data_patch": "", # путь к файлу для обновления данных после сравнения
                "transform_ins_data_patch": "", # то же для данных, полученные для вставки в приемник
                "transform_del_data_patch": "", # то же для удаления
            },
            "comparison": {
                "key_fields": [] # ключевые поля, как правило 1 или 2 (пока одинаковые для источника и приемника)
                                 # todo сделаю в дальнейшем разные поля key_fields
            }

        }
    ]
